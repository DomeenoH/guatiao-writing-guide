## 它是干什么的

向导式写作 skill。写作之前先当向导，按顺序一步一步问：目的、人物、经过、核心冲突、主要矛盾、证据、诉求、平台、自己哪里做得不对。一次只问一步，每步复述确认，信息齐了先列一遍给用户确认，再动笔写。

写出来的瓜条按原教程的结构走：Page 1 标题、Page 2 省流版加时间轴、Page 3 矛盾分析、最后 Q&A 明确诉求。

- `skill.yaml`：skill 描述信息
- `images/`：原教程图片，封面 00.jpg 加教程 01 到 08.jpg

## 内容要点

- 排版规则：思源黑体、字重三档、2 比 3 短图、截图聊天记录前把手机调回默认字体、颜色对比度查 AA 或 AAA
- 结构：标题一句话讲清核心冲突，时间轴按起因、前期发展、冲突爆发、冲突升级、最终结果走，矛盾分析多用可视化
- 态度：不要隐藏对自己不利的记录，客观平和陈述，尽量不要人身攻击，鼓励合理维权
