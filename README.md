# 瓜条写作指南

把边野的瓜条教程变成一个能直接用的写作助手：先一步一步问清你的事，信息齐了再帮你写成路人愿意读完的瓜条。

## 它是干什么的

向导式写作 skill。写作之前先当向导，按顺序一步一步问：目的、人物、经过、核心冲突、主要矛盾、证据、诉求、平台、自己哪里做得不对。一次只问一步，每步复述确认，信息齐了先列一遍给你确认，再动笔写。

写出来的瓜条按原教程的结构走：Page 1 标题、Page 2 省流版加时间轴、Page 3 矛盾分析、最后 Q&A 明确诉求。

## 怎么用

两种用法，挑一个就行。

**用法一：装成 Muse skill**

把本仓库整个文件夹放到 `~/workspace/custom-skills/guatiao-writing-guide/`，搜“瓜条”就能找到。之后只要说想写瓜条，它就会按向导流程先问你，再写。

**用法二：复制下面的提示词给任意 LLM**

不用装 skill，直接把下面这段话复制到你用的 LLM 对话框里发过去，它就会按同一套方法先问你、再写：

```
你是瓜条写作助手，帮我把一次纠纷写成路人愿意读完的瓜条。

方法在这里，先读完再开始：https://raw.githubusercontent.com/DomeenoH/guatiao-writing-guide/main/SKILL.md

按里面的流程来：先当向导，一步一步问我——目的、人物、经过、核心冲突、主要矛盾、证据、诉求、平台、我自己哪里做得不对。一次只问一步，每步复述确认。信息齐了先按标题、省流版、时间轴、矛盾分析、Q&A 列一遍给我确认，确认无误再动笔写。

排版和结构规则以 SKILL.md 为准。方法来自边野的《瓜条教程 1.0 排版篇》。
```

## 文件

- `SKILL.md`：skill 正文，向导流程、排版规则、结构、发前检查
- `skill.yaml`：skill 描述信息
- `AGENTS.md`：给 Agent 看的说明（如果你是 Agent，先读这份）
- `images/`：原教程图片，封面 00.jpg 加教程 01 到 08.jpg

## 内容要点

- 排版规则：思源黑体、字重三档、2 比 3 短图、截图聊天记录前把手机调回默认字体、颜色对比度查 AA 或 AAA
- 结构：标题一句话讲清核心冲突，时间轴按起因、前期发展、冲突爆发、冲突升级、最终结果走，矛盾分析多用可视化
- 态度：不要隐藏对自己不利的记录，客观平和陈述，尽量不要人身攻击，鼓励合理维权
